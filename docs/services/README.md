# Service directory

The service pages describe deployment notes, relevant ports and tasks to verify when the server is online. These links are **not** service health indicators.

### Networking & security

- [Pi-hole](pi-hole.md) — DNS, filtering and query monitoring
- [WireGuard](wireguard.md) — Secure remote access from approved clients
- [OpenSSH](openssh.md) — Remote command-line management
- [Fail2ban](fail2ban.md) — Protect against repeated failed authentication attempts
- [Samba](samba.md) — Authenticated SMB file sharing
- [Syncthing](syncthing.md) — Device-to-device file sync

### Containers & applications

- [Docker](docker.md) — Run the documented self-hosted containers
- [Portainer](portainer.md) — Manage Docker containers, volumes and stacks
- [Homepage](homepage.md) — Central service dashboard
- [Nextcloud](nextcloud.md) — Personal storage with MariaDB and Redis
- [MariaDB](mariadb.md) — Database backing Nextcloud
- [Redis](redis.md) — Redis service associated with Nextcloud
- [Vaultwarden](vaultwarden.md) — Self-hosted password management

### Monitoring

- [Uptime Kuma](uptime-kuma.md) — Track service uptime and latency
- [Netdata](netdata.md) — CPU, RAM, disk and network observability
