# Architecture decision records (ADRs)

Use brief, dated records to explain **why** important architecture choices were made. These are useful to future maintainers and technical reviewers.

Suggested filename: `0001-vpn-gated-management.md`.

## ADR template

```markdown
# ADR-0001: Decision title

- Status: Proposed / Accepted / Replaced
- Date: YYYY-MM-DD

## Context
What constraint or problem requires a design decision?

## Options considered
What reasonable alternatives exist?

## Decision
What will be implemented and why?

## Consequences
What improves? What trade-offs or risks remain?

## Evidence
Link only sanitized diagrams, tests and configuration examples.
```

No ADRs are marked as accepted until a real decision and evidence are recorded.
