# Contributing

This repository documents a personal Linux homelab. Corrections to terminology, links and safe technical documentation are welcome.

## Contribution rules

1. Submit small, clearly scoped documentation improvements.
2. Reference a source or a reproducible, authorized test for factual configuration claims.
3. Distinguish **observed**, **proposed** and **not yet verified** states.
4. Never include credentials, private network endpoints, personal data or unredacted logs.
5. Keep the main README concise and add implementation detail to the service page or relevant guide.
6. Prefer diagrams, checklists and reproducible steps over cosmetic activity counters.

For security concerns, follow [SECURITY.md](SECURITY.md). For operational notes, see [the journal template](journal/README.md).
